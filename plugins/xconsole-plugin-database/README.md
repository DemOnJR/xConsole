# xConsole Plugin: Database & MySQL Explorer 🗄️

Official plugin for **xConsole** providing multi-engine database management, visual spreadsheet-like table editor, live schema viewer, and SQL query workspace for MySQL, MariaDB, PostgreSQL, and SQLite.

---

## 🚀 1-Command Installation

```bash
xconsole plugin install xconsole-plugins/xconsole-plugin-database
```

Or from URL:
```bash
xconsole plugin install https://github.com/xconsole-plugins/xconsole-plugin-database
```

---

## ✨ Features & Capabilities

- **Automatic SSH Tunneling**: Connect securely to remote MySQL/Postgres instances over SSH without exposing database ports.
- **Visual Table Grid**: Edit cells, filter, paginate, sort, and delete rows with immediate safety prompts.
- **Interactive SQL Console**: Execute arbitrary queries with syntax highlighting, latency tracking, and export to CSV/JSON.
- **AI Agent Tool Suite**: Exposes `db_list_connections` and `db_run_sql` to the AI Agent to inspect schemas and diagnose data issues autonomously.
