# xConsole Plugin: SFTP & Remote File Manager 📁

Official plugin for **xConsole** providing dual-pane remote filesystem explorer, inline code editor, drag-and-drop transfers, and file permissions management over SSH/SFTP.

---

## 🚀 1-Command Installation

```bash
xconsole plugin install xconsole-plugins/xconsole-plugin-sftp
```

Or from URL:
```bash
xconsole plugin install https://github.com/xconsole-plugins/xconsole-plugin-sftp
```

---

## ✨ Features & Capabilities

- **Dual-Pane Browser**: Browse local and remote directory trees seamlessly with quick bookmarks.
- **Drag-and-Drop Transfers**: Multi-file and recursive folder transfers with background queue and pause/resume.
- **Integrated Code Editor**: Edit remote configuration files and scripts directly with syntax highlighting.
- **Permissions Inspector**: Chmod numeric and symbolic permissions editor.
