# xConsole Plugin: Analytics & Telemetry

Real-time process telemetry, CPU/RAM/GPU monitoring, model prompt cache hits, and AI tool usage analytics for xConsole.

## Features
- **Live System Telemetry:** Monitor application process RAM, system RAM, CPU usage, and GPU acceleration.
- **Model Cache Hit Ratio:** Real-time visual sparklines for prompt caching performance and token savings.
- **AI Tool Invocations:** Breakdown of most frequently used tools and agent execution patterns.
- **Session Audit Metrics:** Summary of user turns, tool invocations, and conversation history.

## Installation
In xConsole, open the Plugin Marketplace (`🧩`) or install directly via:
```
DemOnJR/xconsole-plugin-analytics
```
